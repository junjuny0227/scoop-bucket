# junjuny0227/scoop-bucket

Scoop manifests for [Repot](https://github.com/junjuny0227/Repot).

```powershell
scoop bucket add repot https://github.com/junjuny0227/scoop-bucket
scoop install repot/repot
```

`bucket/repot.json` is generated by the Repot release workflow (`scripts/cli-packages.mjs`) when a release is published. Do not edit it by hand; change the template in the Repot repository instead.
